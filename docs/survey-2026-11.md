# Mathlib survey for the vector field method (2026-11)

## 中文摘要

本文调研了固定版本 Mathlib（提交 `56a005855ea17e0b0958f73ec801ae140b0a1679`，对应 tag `v4.35.0`）中与本项目相关的已有结果。结论要点：

- **散度/Stokes**：只有长方体（`Icc a b ⊆ Fin (n+1) → ℝ`，以及经线性同构转写的版本）和平面矩形上的散度定理，另有 Henstock–Kurzweil 版本、以及"闭 1-形式沿 C² 同伦的边界积分为零"（单位正方形像上的 Stokes 型结论）。没有球、球壳、`regionBetween` 型区域或流形上的散度/Stokes 定理。`regionBetween f g s ⊆ α × ℝ`，被夹的实变量在**第二个**分量，区间为**开区间** `Ioo`。
- **求导与积分**：变限积分求导（FTC-1）、参数积分求导（控制收敛型）、全空间分部积分（`LineDeriv/IntegrationByParts`）、二元偏导连续 ⇒ 严格可微（`FDeriv/Partial`）均已有；"变限 + 含参"的联合 Leibniz 公式未找到。
- **极坐标**：`Measure.toSphere`、`homeomorphUnitSphereProd` 与测度保持定理已有，径向函数积分公式已有；球面测度的旋转不变性、与 Hausdorff 测度的联系未找到。
- **Sobolev 嵌入**：Gagliardo–Nirenberg–Sobolev（`p < d`）已有；Morrey（`p > d`）缺失；`H^s`（`s > d/2`）只有"Fourier 变换属于 L¹"这一主步骤（`MemSobolev.fourier_memL1`），尚无 `‖u‖_∞ ≤ C‖u‖_{H^s}` 的结论，也没有局部（球上）的经典 `H² ⊂ L^∞`。
- **定义层**：没有 Lorentz 群或 Minkowski 时空。`indefiniteDiagonal p q R` 的指标类型是 `p ⊕ q`，在 `p` 上为 `+1`、`q` 上为 `−1`，与本项目 `η = diag(−1,1,1,1)`、时间在前（指标 `Fin 4`）无法同时在符号与顺序上对齐。Laplacian、gradient 都依赖欧氏内积；`VectorField.lieBracket`、`lineDeriv`、`Matrix.trace`/`LinearMap.trace` 已有。
- **KS-H 与 KS-C**：主要缺口是（i）球上（可伸缩）的 `H² ⊂ L^∞`（三维）；（ii）单位球面 S² 上以 Ω 表述的 Sobolev 不等式；（iii）球面测度的旋转不变性及一般（非径向）函数的极坐标展开的便捷形式。其余（链式法则、伸缩变量替换、截断函数、FTC、Cauchy–Schwarz）都已有。

### 1.3 `regionBetween` API: coordinate direction and interval conventions

Definition
([`regionBetween`, Lebesgue/Basic.lean#L449](https://github.com/leanprover-community/mathlib4/blob/56a005855ea17e0b0958f73ec801ae140b0a1679/Mathlib/MeasureTheory/Measure/Lebesgue/Basic.lean#L449)):

```lean
def regionBetween (f g : α → ℝ) (s : Set α) : Set (α × ℝ) :=
  { p : α × ℝ | p.1 ∈ s ∧ p.2 ∈ Ioo (f p.1) (g p.1) }
```

- **Coordinate direction**: the ambient type is `α × ℝ`; the base point is the **first**
  component, the "vertical" real variable sandwiched between `f` and `g` is the **second**
  component. For a spacetime modelled as `ℝ × ℝ³` with time first, a region
  `{f(x) < t < g(x)}` is *not* literally a `regionBetween` (it would need `ℝ³ × ℝ`, time last);
  one would have to compose with `Prod.swap` (measure-preserving for product measures).
- **Interval convention**: `regionBetween` uses the **open** interval `Ioo (f x) (g x)`. The
  half-open/closed variants are *not* named definitions; they appear only as anonymous sets
  `{p | p.fst ∈ s ∧ p.snd ∈ Ioc/Ico/Icc (f p.fst) (g p.fst)}` in measurability lemmas.
- Measures are `μ.prod volume`.

### 5.2 `indefiniteDiagonal` versus the project's η

```lean
/-- The indefinite diagonal matrix with `p` 1s and `q` -1s. -/
def indefiniteDiagonal : Matrix (p ⊕ q) (p ⊕ q) R :=
  Matrix.diagonal <| Sum.elim (fun _ => 1) fun _ => -1
```

| Aspect | `indefiniteDiagonal p q R` | Project `η` |
|---|---|---|
| Index type | `p ⊕ q` (a `Sum` of two arbitrary types, `[DecidableEq p] [DecidableEq q]`) | `Fin 4` (time index `0` first, then space `1,2,3`) |
| Sign on first block | `+1` on `Sum.inl` (the `p` block) | `−1` on the time index |
| Sign on second block | `−1` on `Sum.inr` (the `q` block) | `+1` on the three space indices |
| Ordering | `inl` block before `inr` block | time first |
| Coefficient ring | arbitrary `CommRing R` | `ℝ` |
| Namespace | `LieAlgebra.Orthogonal` | — |

Consequences: `indefiniteDiagonal (Fin 3) (Fin 1) ℝ` has the project's *signs* (space `+1`,
time `−1`) but puts time **last**; `indefiniteDiagonal (Fin 1) (Fin 3) ℝ` puts time **first**
but has the opposite overall sign `diag(+1,−1,−1,−1)` (the "mostly minus" convention). Either
way, matching `η` requires a reindexing (`Matrix.reindex` with `finSumFinEquiv`/a swap) or
`−indefiniteDiagonal (Fin 1) (Fin 3) ℝ`. Recommendation: define `η` directly as
`Matrix.diagonal ![-1, 1, 1, 1]` on `Fin 4` and, if Mathlib's `so'` is ever needed, prove a
one-off bridge lemma; `indefiniteDiagonal` itself only has the lemmas
`indefiniteDiagonal_transform` (#L208) and `indefiniteDiagonal_assoc` (#L359) for Lie theory.

### 6.3 Recommended route for the shared gap H6 (local `H² ⊂ L^∞` on a ball in ℝ³)

Both inequalities reduce to H6 (KS-C also via C7). A proof avoiding Fourier analysis:

1. Multiply by a cutoff `χ` (C11) equal to 1 near 0 and supported in the ball; set `g = χ w`.
2. For each direction `ω ∈ S²`, apply FTC along the ray and integrate by parts once on `[0, R]`
   (compact support kills the boundary terms):
   `g(0) = −∫_0^R ∂_ρ g(ρω) dρ = ∫_0^R ρ ∂_ρ² g(ρω) dρ`
   (interval FTC / integration by parts in `IntervalIntegral/FundThmCalculus.lean` and
   `IntervalIntegral/IntegrationByParts.lean`).
3. Average over `ω` with respect to `toSphere`, bound `|∂_ρ² g(ρω)| ≤ ‖∇²g(ρω)‖`, and convert
   back to a volume integral by `measurePreserving_homeomorphUnitSphereProd` (C6): since
   `dy = ρ² dρ dσ(ω)`, we have `ρ dρ dσ(ω) = |y|^{-1} dy`, hence
   `|g(0)| ≤ C ∫_B ‖∇²g(y)‖ |y|^{-1} dy`.
4. Cauchy–Schwarz (C10) with `|y|^{-1} ∈ L²(B)`: `|y|^{-2}` is integrable on a ball in ℝ³ by
   [`integrableOn_ball_of_norm_le_rpow`](https://github.com/leanprover-community/mathlib4/blob/56a005855ea17e0b0958f73ec801ae140b0a1679/Mathlib/Analysis/SpecialFunctions/Pow/Integral.lean#L110)
   (`α = 2 < 3 = d`). This gives `|g(0)| ≤ C ‖∇²g‖_{L²(B)}`.
5. Expand `∇²(χw)` by the Leibniz rule; `χ` has fixed bounds, so
   `|w(0)| ≤ C Σ_{k≤2} ‖∇^k w‖_{L²(B)}`. Translate to a general centre `x₀` by translation
   invariance of Lebesgue measure.

All ingredients of this route are present except the packaged non-radial polar formula
(Partial, C6) and the bookkeeping for `∂_ρ² g` versus `∇²g`. Alternative: the Fourier route via
`MemSobolev.fourier_memL1` (needs the classical ↔ Bessel-potential bridge, Fourier inversion
into bounded continuous functions, and an extension/cutoff argument) — heavier.
